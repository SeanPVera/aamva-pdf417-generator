# Published specimen intake

`2026-10-25.json` records public samples downloaded from issuing jurisdictions,
with 258 image assets across 38 jurisdictions, original source hashes and
24 distinct PDF417 payloads
recovered with ZXing-C++ 3.1.1. The symbols were read from published pixels.
Their bytes were not generated by this project or reconstructed from PDF text.

The collection contains driver licenses, permits, identification cards and
standalone calibration symbols. The artwork uses the publishers' sample data.
No private issued credentials were collected. Public sample artwork does not
establish that every issued credential uses the same layout or contents.

## Use the images locally

The accompanying `AAMVA_Corpus_Additions_2026-10-25_v2` asset package contains the
downloaded originals, curated specimen images, a gallery and independently
rechecked barcode crops. Put its contents in
`.corpus-cache/public-specimens-2026-10-25/` to resolve the manifest's relative
asset paths. The cache is ignored by Git. Source URLs and SHA-256 hashes in the
manifest identify the captured documents if a publisher later changes a file.

Publisher ownership and sample markings remain in the artwork. A public URL
does not itself establish an open redistribution license. This commit includes
source metadata and recovered sample data; publisher artwork stays in the local
asset package pending review of its reuse terms.

## What this intake verifies

Every saved evidence image was decoded again after saving and compared byte for
byte with its recorded payload. `src/tests/publishedSpecimens.test.ts` checks all
24 payload hashes and independently transcribed fields for the 20 observations
the current application decoder accepts. Four legacy or malformed observations
remain available without tests that require the parser to reject them forever.

The generator comparison is a snapshot against the manifest's repository commit:
12 payloads produce different bytes, eight contain input the generator rejects,
and four stop at the decoder. No sample matched the generator byte for byte.
Those figures are findings, not assertions that all differences are generator
bugs. Some samples deliberately contain placeholders or source inconsistencies.

Run the parser checks and the captured intake summary with:

```sh
npm run test:run -- src/tests/publishedSpecimens.test.ts
node scripts/published-specimen-report.mjs
```

## Revision 2 additions

The deeper acquisition adds 132 visually reviewed image assets from 23 newly
represented image jurisdictions and four distinct payloads. Exact duplicate
image bytes are omitted. Similar artwork can remain in different resolutions,
reference sheets or annotated versions; the asset count is not a design count.
The original revision remains separately available, and the manifest records
its hash and the revision delta.

- Delaware contributes a 390-byte AAMVA 09 sample with `ZD` data.
- South Dakota contributes a 625-byte AAMVA 04 sample with `ZS` data, recovered
  after adding a white margin and 2x nearest-neighbor scaling.
- New Jersey contributes a 687-byte sample whose leading byte is a space before
  `@`. The app reports `Invalid compliance indicator`. The source bytes remain
  untrimmed, including the `ZN` subfile and expanded placeholders.
- Georgia's older public guides contribute a 395-byte 2013 interim sample with
  AAMVA 06, jurisdiction version 01 and `DAQ333333333`. Its `DDAM` value is
  rejected by the generator. Another guide barcode duplicates an existing
  payload and does not increase the distinct-payload count.

The Delaware and South Dakota samples encode `DDBMMDDCCYY`, which the generator
rejects. Iowa image references are republished in a federal E-Verify factsheet;
the Kansas source is archived by the State Library of Kansas. Colorado's 2021
legislative comparison includes proposed January 2022 artwork and is labeled as
such. Washington DOL limits its unchanged images to aids for validating licenses;
that purpose limitation is carried with each image's metadata.

## Findings that need careful interpretation

- Nebraska's 2026 sample carries AAMVA 11 and jurisdiction version 01. The
  published JPEG needed a white margin and 2x nearest-neighbor scaling to read.
- Virginia's 2023 guide contains padded values and a `ZV` subfile. Its page 3
  card-back image decodes to ALYSSA FAITH JAMES while the neighboring CDL front
  and separate calibration symbol describe WESTON COLE BAILEY. Keep each symbol
  tied to its exact source image.
- Florida's 2019 calibration symbol omits `DAY`. The publisher's field table
  explicitly documents that omission for the described format.
- Texas's 2025 artwork encodes `DDBMMDDCCYY` and other filled sample values.
  Preserve these as sample artifacts; do not weaken production validation.
- Georgia supplies independently decodable material for versions 03, 06 and 09,
  including `ZG` data and old layouts that use `DCT`.
- New York's published samples differ from the existing issued-card profiles.
  The 2013 sample also contains `DAQNONE`. A sample's placeholder values are not
  evidence for a production customer-number format.
- The 2021 Nebraska symbol includes a two-character `ZN` line. The South
  Carolina legacy sample uses record separator `0x1c` and a shorter header;
  the older Florida symbol also has a shorter header.

These are observations rather than passing encoder conformance vectors, so they
live outside `vectors/` and do not increase `MIN_REAL_WORLD_JURISDICTIONS`. To
promote one, follow the parent README, resolve any source inconsistency and
demonstrate the intended generator behavior against the independent bytes.

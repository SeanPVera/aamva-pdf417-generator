## Changes supported by the evidence

Source-specific profiles reproduce older and alternate Virginia, Georgia, Nebraska, Florida, New York, Washington, Kansas, Missouri, Colorado, and Montana layouts. South Carolina and Pennsylvania use explicit mechanical framing transformations; their unmodified originals remain in intake. Profile selection requires matching issuer, edition, document type, and observed layout. The generator never selects one from the state alone.

The parser reads historical 19-byte v01 headers, a leading scanner space, and the observed South Carolina separator variant in compatibility mode. It reports boundary drift and the interior Pennsylvania terminator. Strict validation continues to reject malformed framing. The Nebraska v09 fragment remains a malformed observation.

Version 12 adds the 2026 active field table, DL/ID applicability, fixed widths and indicator rules, mandatory DAD, ISO-8859-1 wire values, opaque SIG/SCV preservation, raw P-256 signature ASCII85, full/partial canonicalization, and verification using a caller-supplied public key. Signed input uses UTF-8 under B.6.2, while barcode bytes use the Annex D character set. No issuer certificate chain, revocation check, or issuer authenticity claim is implemented.

Independent read-back exposed an isolated-byte encoding defect in bwip-js 4.10.1. The pinned 4.11.4 encoder preserves Latin-1 bytes in ZXing-JS and ZXing-C++ checks. The test runtime supplies native character conversion through the public ZXing hook because its Node fallback mishandles Latin-1. Symbol recovery remains independent.

## Source qualifications

- Colorado: a public University of Denver verification manual supplies the 318-byte v10 back. An issuer-authored legislative presentation corroborates the John Driverlicense artwork, but supplies no independently decoded copy of those exact back bytes. The adjacent front in the university guide is from an older edition. This fixture establishes the recovered back layout only.
- Montana: a government-authored brochure rehosted by a scanner vendor supplies the 386-byte v08 sample. The primary government brochure has different raster bytes and did not decode. The source discriminator has 30 characters, beyond the shared 25-character limit, and the face and barcode differ on some printed values. Its named compatibility profile preserves this observed departure without certifying standards compliance. A second 636-byte template retains an invalid DDB placeholder and stays outside positive fixtures.
- Historical Florida: a public training-guide rehost supplies a 419-byte v01 dummy template with a separated identifier. Its named field format applies only to that edition. Direct issuer origin is unverified. Only the reviewed specimen crop is retained in the evidence package.
- California: the retained 607-byte dummy template includes an invalid revision date, overlong fields, and a one-byte boundary discrepancy. It remains a negative observation. A separate personal payload concealed behind dummy artwork was excluded by hash; no private raw bytes or source PDF are redistributed.
- Historical Illinois: an additional 207-byte public gallery sample uses 0x1c and lacks its final segment terminator. It remains malformed evidence.
- Kansas: a government-authored 2017 testimony PDF was recovered from a public repository. A government library copy corroborates the publication but has different rasterized file bytes and does not decode. This is a qualified rehosted publication reference.
- Washington and Pennsylvania: primary publications recovered from dated Internet Archive captures. These historical layouts establish no current issuance date.
- Missouri: the source uses DDA=B and an all-zero revision-date sentinel. The profile scopes those observed values and leaves their meaning unverified.
- Nebraska v11: the source uses a reserved race code from the 2025 table. The exception applies only to the named specimen profile.
- Hawaii: artwork contains another jurisdiction's IIN and inconsistent directory entries. It remains quarantined.
- DC: the barcode contains explanatory example text. It supplies no issuer payload.
- The 2026 standard's worked signature example conflicts with its normative fixed-width raw-signature requirement. The worked example is excluded from passing references.
- Texas, South Dakota, New Jersey, Indiana, Mississippi, and Delaware include literal date placeholders or other invalid sample values. Michigan's public retailer sample omits mandatory values. The encoder continues to reject those defects.

More web searching may recover additional historical sources. Public front artwork, invalid placeholders, generated payloads, and inaccessible source links do not meet that requirement.

Add an opt-in observed encoding profile (`co-issued-v10`) and issued vector for a Colorado DL layout, without changing default Colorado generation.

The profile records jurisdiction version `01`, the issuer element order (including `DCL` and `DCJ`), `omitFinalSeparator`, fixed widths for `DAK`/`DCL`, `preserveValueCase: ["DAU"]`, and a `ZC`/`ZCA` jurisdiction subfile. `DCL` stays excluded under ordinary CO rules and is re-added only when this profile is selected via `encodingProfileId`. Identifying descriptors in the vector are generic stand-ins; `expectedBytes` are regenerated by the encoder under the profile.

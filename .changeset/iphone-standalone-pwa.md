Run on iPhone with no Mac and no computer at all, via an installable hosted PWA.

- Add `.github/workflows/pages.yml`, which builds `dist/` on a Linux runner and publishes it to GitHub Pages on every push to `main`. The app is fully client-side, so a static host is all it needs — the phone just opens a URL and taps Add to Home Screen.
- Add PNG app icons generated by `scripts/gen-icons.mjs` (zlib only, no image dependency). iOS ignores an SVG `apple-touch-icon` and substitutes a screenshot of the page, so the previous SVG-only icon set produced a blurry Home Screen tile.
- Set `viewport-fit=cover`. The three existing `env(safe-area-inset-*)` rules were resolving to 0 without it; the sticky header now pads itself past the Dynamic Island instead of hiding controls behind it.
- Serve navigations network-first in the service worker so a redeploy reaches an installed phone. An iOS Home Screen app has no reload button, so the previous cache-first shell would pin it to a stale build. Assets stay cache-first and the cached shell is still the offline fallback.
- Drop the two Google Fonts `@import`s, which the app's own CSP has always refused, and add `system-ui`/`-apple-system` to the font stack so iOS renders in San Francisco rather than falling through to Helvetica.
- Add `docs/IPHONE.md` and rework the README's iPhone section around the no-computer path.

## 2025-05-14 - Focus Management & Tour Interaction
**Learning:** Adding interactive overlays (like a Welcome Tour) can disrupt keyboard navigation flow and break E2E tests that expect immediate access to the underlying UI. Modals must implement focus restoration to satisfy WCAG 2.1 (Success Criterion 2.4.3), and E2E suites require explicit "dismiss" helpers to maintain stability in CI environments where the tour might persistent across sessions.
**Action:** Always implement focus restoration using `useId` and `useEffect` cleanup for new overlays, and provide a `dismissTour` utility in `e2e/helpers.ts` to be called at the start of all visual/interaction tests.

## 2025-07-18 - Actionable Empty State Pattern for Field Filtering
**Learning:** Generic "No results" or "No fields match" messages leave users stranded. Implementing an "Actionable Empty State" with `role="status"` ensures screen reader announcements. Using high-contrast styling (such as forced `text-gray-900`) is critical when the theme container overrides standard dark mode rules (like DMV state themes forcing white background). Dynamic feedback containing the search terms inside smart quotes and an explicit, accessible primary action button to clear active filters drastically improves user recovery paths.
**Action:** Always provide contextual, smart-quoted search query feedback and an actionable primary clear button for search/filter UI empty states. Ensure text remains visible against potentially forced-white backgrounds by avoiding `dark:text` overrides on containers governed by state theme classes.
